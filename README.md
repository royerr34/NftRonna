# NftRonna

NftRonna aggregates decentralized data streams in real-time, utilizing a high-performance distributed processing engine for scalable network optimization.

NftRonna is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/NftRonna.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

NftRonna is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
